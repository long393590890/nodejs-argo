# 2026-09-15

## nodejs-argo 项目：订阅节点改从外部列表生成
- 需求：用户希望订阅节点从 gist 优选 IP 列表获取（每行格式 `IP:端口#名称`，如 Cloudflare 优选 IP）。
- 实现（index.js，改动约 50 行，其余不变）：
  - 新增环境变量 `NODE_LIST_URL`（默认空），放在 CFPORT 之后。
  - 新增 `fetchNodeList()`：拉取并解析列表，返回 `[{ip, port, name}]`，失败/未配置返回空数组。
  - 新增 `buildWsLinks(add, port, nodeName, argoDomain)`：为单个入口生成 vless/vmess/trojan（ws+tls）链接，host/sni 仍指向 Argo 隧道域名。
  - `generateLinks()` 重构：列表非空时逐条批量生成（节点名前缀 `NAME-`），否则回退原 CFIP 单节点行为；HY2/REALITY/S5 直连节点逻辑不变。
- 用户 gist：https://gist.githubusercontent.com/long393590890/8bb42c5a836c1d8345e43583a78663d9/raw/gistfile1.txt（69 条 CF 优选，全 443 端口）
- 已通过 `node --check` 语法校验。
- 追加需求：新增 `NODE_PROTOCOLS` 环境变量（默认 `vless,vmess,trojan`，逗号分隔），控制订阅生成哪些协议；用户当前只用 vless。`buildWsLinks()` 改为按协议开关逐段拼接。
- 本地运行配置：创建项目根目录 `.env`（已填 gist 列表 + `NODE_PROTOCOLS=vless`），package.json 的 dev/start 脚本改为 `node --env-file-if-exists=.env index.js`（Node 22.22 支持，Docker 内无 .env 也不报错）。
- 部署到 Pterodactyl 面板（elysiannodes，Node 24 通用 egg）：报错 `Cannot find module './index.js'`，原因是面板 STARTUP 的 `MAIN_FILE` 变量未设为 `index.js`（走了 ts-node 分支）。适配方案：把 `NODE_LIST_URL`（gist 地址）和 `NODE_PROTOCOLS`（vless）直接写为 index.js 代码默认值，面板上只需正确填 MAIN_FILE，无需配置额外环境变量；面板会自动 npm install（axios 在 dependencies 里）。
